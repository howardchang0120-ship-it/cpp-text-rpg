# C++ Text-Based RPG Game

A text-based role-playing game developed in C++ using object-oriented programming (OOP).

## Features

- Four classes: Player, Skill, Item, and Monster.
- Turn-based combat with basic attacks, skills, and item usage.
- HP and MP management during battles.
- Monster counterattacks and battle outcome handling.
- Inventory and skill management using STL vector.

## Technologies

- C++
- Object-Oriented Programming (OOP)
- C++ Standard Library (std::vector)

## How to Run

Compile the C++ source file using a C++ compiler.

g++ rpg.cpp -o rpg

Run the compiled program:

./rpg
